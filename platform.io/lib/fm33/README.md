# FM33 support headers

- `fm33lc0xx.h`, `system_fm33lc0xx.h`: device headers from the FMSH FM33LC0XX_DFP 3.0.4 pack, unmodified
  (freely distributable, see the file headers).
- `core_cm0plus.h`, `cmsis_*.h`, `m-profile/cmsis_gcc_m.h`: CMSIS-Core 6 from PlatformIO's framework-cmsis
  2.60300.0, unmodified (Apache-2.0).
- `fm33.h`, `fm33-ext.h`: Rad Pro helpers in the style of `lib/stm32/`.
